# Loan-Approval-Expert-System-IIM-MUMBAI-

A modular, Python-based expert system for automatic bank loan approvals using a combination of collateral evaluation, financial stability analysis, and bank profitability (yield) assessment.
Developed as part of a remote summer internship at IIM Mumbai under Prof. Hema Date by Yogesh D Patil (B.Tech, NIT Rourkela).

Overview
This project implements an expert system that automates and explains loan decisions for banks. The system applies rule-based reasoning to:
•	Assess the quality of collateral provided,
•	Analyze financial ratios and stability,
•	Calculate projected yield and profitability for the bank,
•	Output automated, auditable decisions (approve/reject/review) with detailed explanations for each.


 
Key Features
•	Modular Expert System: Collateral, financial, and yield analysis
•	Rule-Based Logic: Easily extend or modify rules
•	Explanation Facility: Full traceability and audit trail for every decision
•	Ordinal Scaling: Consistency in qualitative judgment & recommendations
•	Data Validation: Clean handling of real-world input data
•	Production-Ready: Designed for easy deployment and integration
